# Python 基础复习

五道练习，检查列表、切片、可变类型、循环与字典的基础知识。

## 1. 单选题
题目：下面代码输出什么？

```python
numbers = [1, 2, 3]
numbers.append(4)
print(len(numbers))
```

A. 3
B. 4
C. [1, 2, 3, 4]
D. 抛出异常

答案：B
解析：append 会在原列表末尾添加一个元素，列表长度由 3 变为 4。

## 2. 单选题
题目：表达式 `"Python"[1:4]` 的结果是什么？

A. "Pyt"
B. "yth"
C. "ytho"
D. "tho"

答案：B
解析：切片包含起始索引，不包含结束索引；索引 1、2、3 对应 y、t、h。

## 3. 多选题
题目：以下哪些 Python 内置类型是可变的？

A. list
B. tuple
C. dict
D. set

答案：A、C、D
解析：列表、字典和集合都可以原地修改；元组的元素引用不可更改。

## 4. 单选题
题目：下面代码输出什么？

```python
total = 0
for number in range(1, 4):
    total += number
print(total)
```

A. 3
B. 4
C. 6
D. 10

答案：C
解析：range(1, 4) 依次产生 1、2、3，相加得到 6。

## 5. 多选题
题目：给定 `student = {"name": "小林", "score": 90}`，哪些表达式不会抛出异常？

A. student["name"]
B. student["age"]
C. student.get("age")
D. "score" in student

答案：A、C、D
解析：访问已有键会返回值；直接索引不存在的 age 会抛出 KeyError；get 在键不存在时默认返回 None；in 检查键是否存在。
